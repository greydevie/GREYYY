# Greymher Llyod M. Loleng — Personal Portfolio Website

A responsive, modern personal portfolio website showcasing my academic background, technical skills, capstone project, and verified Cisco certifications as a 2nd-year Bachelor of Science in Information Technology (BSIT) student at Mabalacat City College.

## ✨ Features

- **Dark & Light Theme Support:** Switch seamlessly between dark and light modes with preference persistence via `localStorage`.
- **Accessibility-First Motion System:** Includes GPU-friendly animations (3D tilt cards, magnetic buttons, interactive hero particle canvas, and scroll reveals) paired with an on/off toggle that respects system `prefers-reduced-motion` settings.
- **Data-Driven Content Architecture:** Skills, projects, Credly-verified Cisco badges, and educational milestones are dynamically rendered from a single `PORTFOLIO_DATA` configuration object in `script.js` for straightforward updates.
- **Interactive Project Filtering & Modal:** Filter projects by category (*Web Development*, *Programming*, *Other Projects*) and inspect detailed highlights and tech stacks in an accessible modal dialog.
- **Bug Squash Mini-Game:** A built-in 30-second browser game with local high-score tracking.
- **Client-Side Validated Contact Form:** Real-time input validation with a `mailto:` fallback and plug-and-play Formspree integration.

## 🛠️ Built With

- **HTML5** — Semantic structure and accessible ARIA attributes
- **CSS3** — Custom properties (CSS variables), Glassmorphism UI, CSS Grid/Flexbox, and keyframe animations
- **Vanilla JavaScript (ES6+)** — Modular DOM rendering, IntersectionObserver scroll animations, HTML5 Canvas particle network, and form validation
- **Google Fonts** — *Inter* & *JetBrains Mono*
